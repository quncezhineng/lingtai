Artifact 01 · Architecture

对话模块架构与依赖关系

上游 LingWu 将对话实现为“事件时间线 + 线程串行执行器 + 实时广播”的三层结构：业务状态在服务端收敛，浏览器只消费事件并维护短期渲染状态。

总览 业务逻辑 交互流程 服务端运行时 前端渲染 REA 证据 分析数据

系统分层

TRANSPORT

REST + WebSocket

REST 负责状态、历史、发送与审批；WebSocket 负责实时事件、增量文本和线程状态。

DOMAIN

MuseService

线程注册、消息校验、附件、inbox、worker、停止、清理、重启修复与状态快照。

EVENT

Timeline + EventBus

Timeline 持久化有序事件；EventBus 向每个 WebSocket 客户端扇出 JSON 消息。

PRESENTATION

React Store + ChatScreen

WebSocket 消息归并到 reducer，临时流独立渲染，完成后由持久化消息替换。

服务端模块

Timeline：线程事实日志

lingwu/server/events.py:39-158

每个线程拥有独立的 Timeline。事件由 add() 追加并自动生成 id 与 ts；超过 2000 条时从头部淘汰。持久化使用临时文件写入后 replace()，避免读者看到半写文件。写入合并延迟为 0.3 秒，并在线程池中执行磁盘 I/O。

有序有界JSON合并写盘原子替换

EventBus：实时扇出

lingwu/server/events.py:161-184

每个订阅者获得一个 asyncio.Queue(maxsize=1000)。发布使用 put_nowait()；队列满时直接移除该订阅者，形成“慢客户端断开而非无限缓冲”的背压策略。

API：REST 与 WebSocket 边界

lingwu/server/api.py:609-619, 1961-2003, 2070-2084

GET /api/threads/:id/events 支持 limit 与 before 游标，返回 has_more。WebSocket /ws 先 accept，再要求首帧 {"kind":"auth","token":"..."}；认证失败关闭码为 4401，成功则订阅事件队列并发送包含完整状态的 hello 消息。

MuseService：线程编排

lingwu/server/service.py:376-455, 800-880, 1072-1173, 1238-1295

服务聚合线程表、时间线、代理、审批、记忆、目标、日历、云端同步与设备 hub。发送路径先生成用户可见事件，再投递到线程 inbox；worker 以线程为单位串行消费，保证同一对话不会并发运行两轮模型。

Web UI 适配器：业务回调转事件

lingwu/server/webui.py:330-404

emit() 统一写时间线并通过 EventBus 发布 kind=event。patch() 发布 kind=update，用于审批状态、工具状态、浏览器帧等原地更新。on_text_delta() 负责临时流的开始与增量。

前端模块

api.ts：连接与错误分类

connectWs() 使用同源 WebSocket，在 onopen 发送首帧认证。关闭码分为三类：4401 需要重新认证，4404 表示运行时已结束且不再重试，其余使用 500ms 起、15s 封顶的指数退避。

store.tsx：事件归并

applyWs() 处理 hello、event、update、stream_start、delta、stream_end、status 等消息。页面把同一事件循环到达的帧微批处理为一次渲染；断线重连后重新加载当前线程历史。

ChatScreen.tsx：渲染与滚动

事件按类型分派到用户气泡、助手气泡、工具芯片、审批卡、问题卡、通知、产物卡、浏览器卡、hands 卡与 hold 卡。混合流气泡在最后一块显示闪烁光标。

滚动策略使用 120px 跟随阈值和 400px “Latest” 按钮阈值；ResizeObserver 同时监听列表与内容高度，处理图片、代码块或字体加载后的布局增长。

Cards / FileViewer / Markdown

产物卡显示标题、路径与类型；HTML 和图片提供缩略预览，点击进入查看器。Markdown 会把回复中的工作区文件路径转成可点击按钮；外链统一 target="_blank" rel="noreferrer noopener"。

事件与消息模型

类型作用关键字段
TimelineEvent线程时间线事实id, ts, thread, type
user / assistant对话内容text, files, reasoning, model_used
tool / approval / question执行过程与人工介入status, risk, args, summary
artifactAgent 生成的文件path, name, action
browser / hands / hold外部执行面状态URL、帧、动作、步骤、持有状态
WsMessage实时传输信封kind; event; thread; 流 id 与 text

流式文本不是独立持久化实体：它是时间线的“进行中视图”。完成后，on_assistant_message() 先发 stream_end，再把同一 id 的 assistant 事件写入时间线。
